# Bulls and Cows Game 🎯

This project is a simple **Bulls and Cows** game implemented in Python as part of the **Engeto Online Python Academy**. The goal of the game is to guess a randomly generated **four-digit number** where:
- Each digit is unique.
- The number does not start with 0.

## 🔹 How the game works:
- The game generates a random **4-digit number** with unique digits.
- The player repeatedly enters guesses.
- The game provides feedback:
  - **Bulls** 🐂 → Correct digit in the correct position.
  - **Cows** 🐄 → Correct digit in the wrong position.
- The game ends when the player correctly guesses the number.
- The program evaluates performance based on the number of attempts.

## ✨ Key Features:
- **Random secret number generation** with unique digits.
- **Input validation**: Ensures the guess is a valid four-digit number.
- **Game logic with bulls and cows scoring**.
- **Performance evaluation** based on the number of attempts.
- **Time tracking**: Measures how long the player takes to solve the game.
- **Clear and structured output** for better user experience.
